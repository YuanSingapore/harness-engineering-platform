# Vocabulary Strategy: English Buddy

## Student Profile

- Singapore MOE Primary 4, current term: Term 3

## Difficulty Mix

- **60%** core basic vocabulary (P4 level)
- **40%** upper P4 vocabulary (bridging toward P5)

## Selection Rules

- Prioritise high-frequency words
- Include words commonly seen in comprehension passages
- Include words useful for composition writing
- Avoid introducing too many difficult words in a single session

## Adaptive Rules

- If Xiaowei repeatedly masters a word → reduce its frequency in future sessions
- If Xiaowei repeatedly struggles with a word → schedule additional review using new or similar contexts
